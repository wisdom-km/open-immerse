# ArXivHub 备忘

备忘，待融合（Wisdom 2026-10-12），不改当前路线图顺序。

来源：[ArXivHub](https://github.com/Peaceful-World-X/ArXivHub)（MIT）。它是链接导航站，不是 PDF 阅读器。下面只记可借的做法和明确不抄的部分。层号、运行时顺序、文献库第 8 步都保持现状。

## 可借

- **编号和元数据。** 规范化 arXiv 编号，并用官方 arXiv API、DataCite API 取题名、作者、DOI 和 BibTeX。结果供运行时第 1 步（第零层 arXiv 源码）和文献库使用。不把这一步改叫第一层，层号不动。
- **KaTeX 安全渲染。** 模型或看图返回的 LaTeX 先写进 `textContent`，再 auto-render。`trust: false`，`throwOnError: false`。用于问 AI 和多模态返回的公式，不替换第零层已确认的核对规则。
- **外部请求要扛得住。** 超时、缓存、在途请求去重、把限速退避记下来、滤掉占位文字。多模态适配器和 OCR 适配器都按这个做。
- **以后：「在…中打开」。** 选择工具条或文献库卡片上放一个菜单，收 5–8 个站点（alphaXiv、Semantic Scholar 等），并允许用户自定义 URL 模板。这一条以后再做。
- **以后：引用次数。** 文献库卡片上显示引用次数。这一条以后再做。

## 不抄

- 不抄第三方代理（`r.jina.ai`、microlink）。有隐私问题，也不稳定，和本地优先冲突。要数据就直接调官方 API。
- 不抄那张 100 多个站点的表，也不抄用户脚本那套界面。
- 许可证是 MIT。若复用它的代码，保留版权声明。
