# 桌面版计划（F11）

2026-10-13 17:44 Wisdom 批准。6 个问题全部按推荐。基线 main@`6eb6486`。本文只记范围、接口和交给谁做，不含视觉设计。视觉到时交给 Loom。

## 已定

1. Electron 套壳。同一份前端代码，加平台适配层 `lib/platform/`。现在只在扩展里做不改行为的重构，F11 才建桌面外壳。
2. 签名先做 Mac。Windows 先发不签名的测试版。
3. 桌面版不做网页翻译。以后做 F11b：插件发送到桌面文献库。
4. 桌面版启动本机已装好的本地服务，不打包进安装包。
5. 插件保持免构建。只有桌面版用 esbuild。
6. 桌面版文献库先用 IndexedDB，PDF 存成文件，以后通过同一个接口换 SQLite。

桌面版 v1 包含：PDF 阅读、翻译、笔记、文献库（首页）、多模态 / OCR、arXiv 源码、问 AI、学习中心、文档翻译页。不包含网页翻译、字幕、划词工具条、右键菜单、Alt+T 和 popup。

## 路线图

F11 是 Windows / macOS 桌面版，排在 F8 之后，和 F10 并行或排在它后面。不早于 F8 完成。F11b 排在 F11 之后：插件把论文或 PDF 发送到桌面文献库。适配层的小 PR 不占 F11 的位置，现在就插进框架间隙。

## 现在预留的平台适配层

目录：`lib/platform/`（零构建 ES module）。扩展保持免构建。

- **F4 PR-2**：平台骨架（`kv`、`library`）。文献库的 store 通过 `platform.library.open()` 拿到，不在 `library-store.js` 里直接 `indexedDB.open`。PDF 原文件走 `BlobStore`。再加一个共用的接口契约测试，以后换 SQLite 时跑同一份。
- **F4 PR-3**：版面缓存走 `kv`。8765 的读取和探测走 `net.fetch`。多标签页广播走 `bus`。
- **F4 PR-5**：GLM-OCR 的启动走 `localServices`。
- **P-A** 统一网络层：超时、重试、缓存、去重；日志里遮住 key；测试里禁止真实请求。不改行为。必须在 F7 之前合入。
- **P-B** `secrets`：和设置页重设计一起做。
- **P-C** `bus`。
- **P-D** 小接口：剪贴板、外链、通知等。
- **P-E** `localServices`。

P-A 到 P-E 都是另开的小 PR，不改现有行为，可以和 F4 并行。
