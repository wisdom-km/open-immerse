## 0. 地基：mm-page 数据形状（已核实）
`lib/mm-page.js` 提示词要求模型返回：
`{"v":…, "columns":1, "blocks":[{"id","label":"heading|text|caption|formula|figure|table|footnote|header","bbox":[x0,y0,x1,y1](0–1 相对整页),"order":1..n,"text","latex","conf"}]}`
- 解析时 bbox 被 clamp，order 去重后重排为连续；缺 bbox 的块由 `attachMissingBbox` 从文字层块借用。
- `mm-page-queue.js`：一次只发一页视觉请求，当前页优先。
→ 每块已有「位置 + 类别 + 顺序」，镜像视图需要的几何信息基本齐备；缺的是：块内字号/行高估计、页面底图（可用 pdf.js 已渲染的 canvas）。

## 2. 决策摘要（已定稿，Wisdom 10-27 17:54 经 Forge 转达）
1. **镜像版面视图**：有分栏/侧栏/框的页，译文按原版面位置摆放；允许纵向扩展，允许留白，但**块之间的相对位置必须与原文一致**。
2. **统一字号**：全部译文用同一字号与行高（不按块缩放）。**不缩字号、不压行高、不截断**；放不下就向下长高，整页随之变高。
3. **表格与图（含图表）**：直接裁剪原页对应 bbox 的图像放入，不翻译、不加角标。**公式**走现有公式回退链：arXiv 源码 → 多模态 → OCR API → 自建识别 → 矢量重绘 → 裁图 → 占位；裁图只是其中一级。
4. 布局算法 = **行带（row band）**：把块按纵向重叠分组成水平带，带高取带内块扩展后高度的最大值，后续带整体下推。
5. 左右滚动按**块/行带对齐**，不按页对齐。
6. 视图：`流式 | 对照 | 镜像` 三态切换，默认流式，按文档记忆（此项未被推翻，沿用）。
7. **统一字号取值**（Wisdom 10-27 17:57）：镜像视图的统一字号跟随阅读器正文字号，用户可用 Aa 调整。

## 4. 行带（Row Band）分割与排版规则
### 4.1 输入
每页 mm-page 块：`{id,label,bbox:[x0,y0,x1,y1](0–1),order}`。先换算为原页 CSS 像素：`Y0 = y0×H`，`Y1 = y1×H`。
`header`（页眉页脚）单独处理：页眉固定在页顶带，页脚固定在页底带，不参与中间分组。

### 4.2 分组算法
1. **全宽块**：宽度 ≥ 页面内容宽 ×0.6（标题、作者、摘要框、通栏图）→ 自成一带（单块带）。
2. **侧栏/跨带长块**：高度 > 页内容高 ×0.4 且宽度 < 内容宽 ×0.35（如 Lancet 右侧窄栏）→ 标为 `spanning`，**先不参与分组**，见 4.4。
3. 其余块按 Y0 排序，扫描合并：若块与当前带的纵向区间重叠 ≥ 较小者高度的 30%（或 Y0 < 带当前 Y1 − 4px），并入该带，带区间取并集；否则开新带。
4. 带的纵向区间也会与全宽块互相切断：全宽块之前、之后各自成带，不跨越。
5. 同一栏内上下相邻的两个段落若被合进同一带（因为另一栏有个长段横跨二者），保留它们在带内的**相对 Y 偏移**（见 4.3）。

### 4.3 带内排版与带高
- 统一字号 `--oi-reader-mirror-font`（= 阅读器正文字号，随 Aa 调整；Wisdom 10-27 17:57 已定）、统一行高 `--oi-reader-mirror-leading`。
- 每块宽度 = 原 bbox 宽（随缩放），左 = 原 X0；按统一字号排版得到**译文自然高度 h'**。块的扩展高度 `H' = max(原高, h')`（短译文保留原高 → 相对位置不变，留白可接受）。
- 带内块的新 top = 带新起点 + (块原 Y0 − 带原 Y0) + 该块上方同栏块的累计增高（同栏内上下块之间也顺推，保持栏内顺序不重叠）。
- **带高 = max(带内每列底部扩展后位置) − 带新起点**，且 ≥ 原带高。
- **下推**：带 k 的新起点 = 带 k−1 新终点 + 原两带间距（原间隙保留）。后续所有带整体下移，带内相对位置不变。
- 图/表/公式块：高度固定为原 bbox 高（裁图不变形），只被下推。

### 4.4 侧栏（spanning）
- 侧栏的原纵向区间覆盖若干带 [k…m]。其 top 跟随带 k 的新起点 + 原偏移。
- 侧栏译文自然高度 h' 若 > 带 k…m 新总高 → 把超出部分加到带 m 的高度上（推下后续带）；若更短 → 底部留白。
- 侧栏所在列在这些带里视为被占用，带内其他列的块不向侧栏方向扩展宽度。

### 4.5 退化
- 单栏页：每块一带，等价于"按原位置的流式"。
- 块 bbox 互相重叠（模型误差，IoU>0.5）：按 order 合并为一块。
- 缺 bbox 的块：按 order 插到前一块之后的同列。

## 6. 逐屏规格
### 6.1 视图切换
三态分段控件，`Alt+1/2/3`；默认流式；按文档 hash 存 storage，设置页可改全局默认。切换只淡入淡出，并按当前锚点块对齐滚动位置。

### 6.2 页面长高的显示
- 译文页高度 = 计算值，可大于原页；**不缩放回原页高**。
- 页与页之间 `--oi-reader-mirror-page-gap` + 1px 分隔线；分隔线左侧页码标签「第 3 页」，若增高 >10% 追加「· 比原文长 32%」（muted，小号）。
- **底图：去掉整页淡化底图**（拉伸后与译文错位，反而误导）。推荐只保留：①图/表/公式的原图裁剪；②原页的**框线与底色块**（如摘要框底色）—— 若要，按块各自裁剪背景并随块拉伸为纯色框（`--oi-reader-paper` 之上加 1px `--oi-reader-line` 边框），不拉伸像素。
- 页眉/页脚：页眉在页顶，页脚贴在增高后的页底。

### 6.3 文字块
- `text/heading/caption/footnote`：统一字号，heading 仅加粗，不放大；文字从块 top 开始排，不垂直居中。
- 块不加滚动条、不截断、不省略。

### 6.4 图 / 表 / 公式
- 按 bbox 从 pdf.js 已渲染的高分辨率 canvas 裁剪原像素（随缩放重新裁，保证清晰）；尺寸 = 原 bbox，不翻译。
- 图题/表题（caption）作为文字块正常翻译。
- 公式不单独设计：按现有公式回退链（arXiv 源码 → 多模态 → OCR API → 自建识别 → 矢量重绘 → 裁图 → 占位）取第一级可用结果；有 `latex` 时悬停可看。

### 6.5 左右滚动同步（按块/带对齐）
- **锚点** = 当前滚动源窗格中，视口顶部以下第一个可见块的 id（部分可见时取 top 最靠上且可见高度 ≥ 8px 的块），再加块内进度 `p = (视口顶 − 块 top)/块高`（0–1）。
- **映射**：块 id 两侧一一对应（同一 mm-page 块）。原→译：找到译文同 id 块，滚到 `译块 top + p × 译块高`；译→原：反向同理。
- **高度不一致的带**：在带内按块进度 p 线性映射；当一侧滚到某块之下的**留白**（如译文带里短块下方的空白，或原文侧较短）时，以所在带为单位：`q = (视口顶 − 带 top)/带高`，另一侧映射到同带同比例位置。效果：长带时对侧"放慢"，不会跳页。
- 防抖：只由用户主动滚动的那一侧驱动（标记 `scrollSource`，100ms 内忽略对侧回调），避免互相触发。
- 无对应块（页眉、mm-only 块）：跳过，取下一个有映射的块。

### 6.6 交互
- 悬停/点击块：对侧同 id 块描边 `--oi-reader-mirror-link-ring`；点击固定，Esc 取消。
- 选区工具栏与流式一致，选区限单块。
- 笔记锚 `{page, blockId, start, end, quote}`，三视图共享；重译后 id 变化用 quote 模糊重锚。

### 6.7 空态 / 加载 / 错误
- 加载：先按**原高**画带骨架（bbox 灰条，`--oi-reader-muted`），译文到达后重算带高并下推；重算时保持当前锚点块不动（滚动补偿），避免内容跳动。
- mm-page 未返回：该页先用流式块，状态行「版面识别中，完成后切换为镜像」。
- mm-page 失败/低置信（conf<0.5 的块 >30%）：该页退回流式，状态行「本页版面未识别，已按流式显示 · 重试」。
- 未开启多模态：「镜像」按钮禁用，提示「需在设置中开启多模态」。
- 单块翻译失败：块内显示原文 + 「重译」链接；高度按原文算。

风险：
1. **bbox 误差**直接影响分带（错把两栏合并/拆开）→ 阈值需样本调参；低置信页退回流式。
2. 中文统一字号若大于原文，**页面增高可能很多**（30–80%），左右进度差距大 → 依赖块级同步。
3. 异步到达导致反复重排、滚动抖动 → 锚点滚动补偿是硬要求。
4. 侧栏很长时会把整页拉高、主栏留大片空白（已被接受，但需观感验证）。
5. 裁图在高缩放下的清晰度与内存。
