# M1 漏字库存（文字层）

口径沿用 rubric v3 的 (a)(b)(c) 和 R2。上下标拍平、行末连字符不算泄漏。

| 类 | 表面现象 | 本刀处理 |
|---|---|---|
| (a) | `（公式槽待对齐）`、`（引用待对齐）`、未替换的 `⟦fN⟧` | 内部函数仍返回这些串，供对齐判断。通读 DOM 和导出 Markdown 不渲染它们，改成「公式 / 引用」角标，原文在左栏 |
| (b) | `a11111…`、纯点线装饰、`OPEN ACCESS`、页边 ORCID `ID` | 装饰串任意位置丢弃；开放获取整行丢弃；`ID` 仅在页边且字号很小，或字体名像图标时丢弃 |
| (c) | `þ→+`、`¼→=`（公式字体或紧挨运算符）、Symbol 的 `å→Σ`、`¼→…`、CMEX 单独的 `r→∑`、`pﬃﬃ→√`、`speci c` 一类连字空洞 | `lib/pdf-glyph-sanitize.js`，版本 `m1-1`。`==` 保持不变 |
| R2 | ZWSP、ZWJ、ZWNJ、BOM、软连字符等格式字符 | 从文字项和块文本剥掉 |

页眉页脚另计噪声：刊名条、文章类型（METHOD 等小字）、卷期 / DOI / ISSN 整行、带年份或 et al. 的 running header。位置带大约是页顶、页底 8%，再加左右页边。`Abstract` 和加高的 `Methods` 标题留在正文。

## 残差（不在本刀硬改）

- 字形映射（m1-2）：Symbol 的 `U+F0xx` 按 Adobe Symbol 字节表还原（τ θ δ ρ σ λ、项目符号）；CMEX 的 `U+F8EB–F8FE` 还原成括号零件；APS 的 `AdvP` 字体里 `þ` 是加号、`ð…Þ` 是括号、`¼` 是等号。`þetta` 这种贴着字母的词不动。
- 对不上编码的私用区、U+FFFD，以及无法判断的松散 `þ/Þ`，整段换成 `⟨⋯⟩`（`GLYPH_GAP_MARK`）。不猜字母。多模态对照可以换掉这个跨度。已知会落到这个标记上的是第 53 篇的 `U+E103/E09D/E104`，以及第 19 篇 CMEX 里的 U+FFFD。Wingdings 的 `U+F0xx` 同样标记，不当成希腊字母。
- 花体括号，以及「等号其实是斜杠」。等号一律不动，避免把真等号和 `==` 改坏。
- 正文里的真 `¼`（如 “¼ of”）和冰岛语 `þetta` 不动。紧挨数字的 `2¼` 也不改成等号。
- 连字表只覆盖一份学术英语词表。表外的空洞留在残差里，扫描能认出表内剩余项。
- 复杂版面的侧栏和装饰层若规则没盖住，仍留在这条文字层兜底上。多模态重建是附录 R，另开分支。本分支不输出跨栏分流信号。
- 双栏正文按栏阅读：左栏自上而下，再右栏。同一基线上跨过栏间距的左右两段会拆开。标题这种横跨整页、中间没有栏间距的行保持一整行。每个段落保留自己的 bbox，便于以后和多模态段落对齐。
