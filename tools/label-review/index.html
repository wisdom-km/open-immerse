默认按约 1000 个单元的复核集往下走。Enter 或「看过，下一个」记下当前单元并跳到下一个。再次点开队列，或用 j / k 回来，选中的是这一页上现在的成员，不是当初预标注的名单。单元队列里 j / k 是上一个或下一个单元。整页队列里 j / k 在低置信度元素之间跳。n / p 翻页。点击只选中一个字形。拖选要盖住元素中心和大约六成面积，只擦到边的宽正文不会选中。Shift 追加，按住 Alt 拖动是减去，Ctrl 或 Cmd 点击可以取消单个元素。按 z 把当前红色单元放大到大约半个画面宽，最大 400%，再按一次回到原缩放。红色实心是当前要核对的单元，灰色细框是其他预标注，橙色虚线是你的选区。拖出方框后按 m，框里的字形和路径成为同一个单元，没框到的成员留在原单元。带普通单词的宽正文不会被改成公式。选中单元的一部分再按 s，这一部分拆成新的行内单元。只选中 (1) 再按 e，把它标成同一行旁边那个单元的公式编号。合并或拆开失败时，结果会停在右栏，Enter 不会把这一选区记成已复核。缺 PDF 时会挡住画面，这时确认和快捷键不起作用。左侧每一条前面的 `#N` 是队列序号，和审计报告一致。整页队列也会标出这一页包含的序号。按 `g` 把光标放进顶栏「跳到 #」，输入数字回车就打开那一条。地址栏加上 `?q=N` 也可以直接打开。
