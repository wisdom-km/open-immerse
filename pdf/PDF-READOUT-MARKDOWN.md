# PDF 右栏 · Markdown 通读流（PDF-READOUT-MARKDOWN）

**定稿（2026-09-19 Wisdom via Anvil）：**  
左栏 **pdf.js 原文**；右栏 **抽取标题+正文 → 翻译 → Markdown 通读流**。  
**不**做像素复刻图 / bbox 版式镜像。

**作废（本定稿起）：**  
`PDF-READOUT-MIRROR.md`、`PDF-MIRROR-LAYOUT-FIDELITY.md`、以及以其为准的「全镜像 V3 / 按页 bbox 摆译文」实现目标。  
（`PDF-MIRROR-CJK-CLIP` / KaTeX 镜像合同一并停作产品目标；公式若出现在通读流中，按下方 §3 处理。）

**fixture：** Attention Is All You Need / arXiv 1706.03762  
**入口：** 本 PR **不**藏弹层 PDF（ENTRY-SECONDARY 已在本轨取消）。  
**排版数字：** 右栏通读继续跟 `.oi-pdf-h1` / `h2` / `p`。

---

## 1. 决策锁

| 项 | 锁定 |
| --- | --- |
| 左栏 | pdf.js 渲染原文；连续滚动 / 翻页保持现能力 |
| 右栏 | **Markdown 通读**：标题 + 正文段落译文，连续可滚阅读 |
| 抽取 | 文本层：主标题、章节标题、正文段；**阅读序** |
| 图 | **不**像素复刻嵌入右栏；题注可作一段文字译（可选）；图本身看左栏 |
| 公式 | 通读流内优先可读文本 / LaTeX 源（`$…$`）；不要求 bbox 贴左 |
| 范围 | 顶栏仍 **当前页（默认）/ 全文**；全文=多页抽取接成一条通读流 |
| 导出 | 右栏内容可导出 MD（及现有 PDF 导出若仍在）；导出=通读语义，非版面引擎 |

否决：右栏按 bbox 贴作者格/双栏几何；右栏贴图复刻；为镜像再开 #40 类 tip。

---

## 2. 右栏信息架构

```
.pane-translate
  .readout          ← Markdown/HTML 通读根（非 .mirror-pages）
    h1 / h2 / p     ← 译后标题与自然段（.oi-pdf-h1 / h2 / p 可保留）
  空态 / 译中态     ← 沿用「点击翻译」「正在翻译，请稍候…」
```

- **不要**默认挂 `.mirror-page` / 绝对定位 `.mirror-item`。  
- 「通读 | 版式」若 UI 仍在：**通读为唯一产品路径**；版式入口可隐藏或标注停用。

---

## 3. 抽取与分段

| 规则 | |
| --- | --- |
| 标题 | 页内主标题 → `h1`；小节 → `h2`；勿把作者行当 h1 |
| 正文 | 文本层合并为自然段 → `p`；禁止「标题一块、一句一块」碎卡片 |
| 阅读序 | 单栏自上而下；双栏则左列再右列，再进下一页 |
| 跳过 | 页眉页脚重复、纯页码、印刷装饰；边栏 arXiv 竖条 **不进** 通读主文（可忽略或脚注一行） |
| 图 | 不嵌入；可选 `[图]` / 题注译文一段 |
| 公式 | 能还原则 MD 内 `$`/`$$`；否则省略或「（公式见左栏）」一句 |

翻译：复用现有 batch / provider；按段请求；当前页 vs 全文跟顶栏 scope。

## 4. 验收（Attention 全文）

打开 fixture，右栏通读：

### 首页

- [ ] 有中文标题（注意力…类），非乱码  
- [ ] 摘要/开篇为 **连续段落**，非叠字作者格、非 arXiv 串进正文  
- [ ] 左栏仍为清晰 pdf.js 原文  

### 全文

- [ ] 切「全文」或翻多页：右栏接成通读流（或按页追加但阅读连续）  
- [ ] 抽检 ≥3 内文页：标题层级可读，段落可滚读  
- [ ] **无** bbox 镜像式作者格糊叠  
- [ ] 导出 MD：标题+段落文本可读序  

### 回归

- [ ] 网页翻译 / Options 间距 **不**被本单改坏  
- [ ] 本 PR 不藏弹层 PDF 入口

## 5. 工程提示

1. 停用 mirror layout 管线；右栏只跑 extract→translate→readout mount。  
2. 抽取走 continuous readout / 段合并，勿再跑 bbox relayout 作为主路径。  
3. 测试以 Attention MD 快照或右栏文本顺序断言，而非 bbox 相交。
