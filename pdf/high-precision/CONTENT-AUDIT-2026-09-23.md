## 为什么简单补一个正则不够

1. `savedTranslationFor` 一旦见到 `libraryDoc.readout` 就返回整篇旧译文；`renderArticle` 随即提前渲染它。库中 `pages` 为 0，旧正文节点也没有 `data-page` / `data-block-id`。因此第 2 页不能自动找到对应译文，“当前页”无法只显示该页。
2. `readout.md` 是旧的展示产物，不是“原文块 → 译文块”的可信索引。其缺失的摘要和 Encoder 正文无法由更好的 Markdown 解析或 CSS 找回。旧库图片即使来自同一文件，也缺逐张图的页码和 bbox，不应替代当前原页裁图。
3. 当前 `textLayerToBlocks` 在混合文字/数学字体的行上会先冲刷已有段落，再为局部数学字体建图；`mixedDraft` 的公式区域没有把普通字体的底数、等号、数字作为一个整体求 bbox。`blockRenderPieces` 在译文丢掉公式占位符时会把图片追加到段末，也不能保证回到原位置。
4. `translatePageBlocks` 直接接收模型返回的译文，目前没有对源文与译文的引用编号、数值、受保护公式占位符做一致性校验。旧库的 `[ , , ]` 证明这种缺口实际发生过。

## 执行方案

### P0：内容台账与失败状态

- 保留旧 `readout.md` 和备份；以该哈希的 PDF 文字层生成 15 页源块清单，记录 `page`、现有块 ID、原文、bbox、块类型。
- 对旧译文按页/章节顺序做一次性迁移，只把**能明确对上**源块的译文放入现有 `pages.pairs_json` 与每页 JSON；配对同时检查引用、数字、公式占位符。优先精核第 1–4 页，再覆盖全 15 页。
- 记录每个源块为“已配对 / 译文缺失 / 对应不确定 / 视觉对象”。不要让 `readout` 覆盖已经验证的逐页配对；未配对块在右栏明确提示，状态不能写“全文已翻译”。
- `[5, 2, 35]` 这类能从同一源块确定的引用可原样恢复，不需重译。摘要和 Encoder 中文正文在当前库及备份中均不存在。用户已明确授权**只补译确认缺失的段落，其他旧译文不重译**；应先完成全篇覆盖率清单，再只把这些缺段的文字层原句送去现有翻译通道，结果以源块 ID、原文和译文写回逐页库。无法确认缺失的块不自动补译。

### P1：原文与公式分块

- 以段落为单位聚合文字层，先生成稳定的原文段，再在段内定位公式跨度；不要因为一个数学字体片段就把整段切成“残句 + 图 + 残句”。同一句源块只生成一次译文。
- 行内 `N = 6`、`d_model = 512`、`z = (z_1, ..., z_n)` 要将普通字体底数、下标、括号、等号、数字合成完整 bbox，并用一个不可译占位符保留原位。独立公式整行裁图。bbox 小得只覆盖 `= 6` 或 `= 512` 时判失败，不能上屏。
- 引用编号作为受保护片段，翻译前后逐组核对；占位符缺失或移位时不把图片追加到句末，而是保留该源块为待核对状态。

### P2：图表只取当前原页

- 图、表在当前 PDF 的同一页确定完整对象边界，裁框包含图内标题与全部子图；图内文字项从可译正文中剔除。第 4 页 Figure 2 须把左右组件与矢量文字合成一块，第 6、8 页 Table 1/2 须形成整块表格。
- 本机版面服务只能辅助给出候选区域；第 3 页实测没有公式类别，因此公式候选仍需文字层几何规则。无法确认完整边界时提示看左栏原页，不展示旧库的小碎图。
- 库内优先存 `hash + page + bbox + role`，阅读时从当前打开的 PDF 裁图；旧 Markdown 中嵌入的 data URL 只用于迁移比对，不作为权威画面。

### P3：右栏逐页渲染与验收

- “当前页”显示当前页配对块，“全文”按页拼接；每个节点带 `data-page`、源块 ID。切页和点击定位均使用这些锚点，不用整篇字符串长度猜位置。
- 对该 PDF 的网页验收至少看：第 1 页摘要正文是否有可信译文或明确缺失；第 2 页 `[13]`、`[7]`、`[5, 2, 35]` 和 `h_t`/`h_{t−1}`；第 3 页 Encoder 全段、`N = 6`、`d_model = 512`、图 1；第 4 页完整 Figure 2 与 softmax 公式；第 6、8 页整张表。右栏不得出现裸 base64、`[ , , ]`、`[ ]`、残公式、重复正文。
- 已入库 PDF 打开时查库并渲染，网络/消息记录中不得出现新的 `OI_TRANSLATE_BATCH`。`node --test tests/*.test.mjs` 通过后仍必须做指定 Chrome 扩展页左右栏人工复核。
