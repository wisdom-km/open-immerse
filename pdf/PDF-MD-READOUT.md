## 1. 产品事实

- 译文跟抽出的原文一致：不增主张、不漏句子、不改数字和变量名。
- 公式、图、表跟打开的 PDF 是同一套内容。默认用 pageRaster 原页裁图。内嵌图原样取出、原页矢量原样搬移也可以。换手段时，右栏这一块仍须与左栏同一区域的内容一致；做不到就退回裁图。认成 LaTeX 再渲染、重画图内英文，不采用。公式画面不来自 LaTeX 渲染。
- OCR 认错的字母不上屏，也不得送进翻译。把 `i` 认成 `n`，或把 `n` 认成 `i`，都算失败。
- 有文字层的正文用文字层原句。这是主场景。没有可信文字层时，正文才用识别结果，并在右栏标明可能有误差。公式、图、表仍是原页裁图。划区框内的字母不进正文。文字层兜底时，一行里除去公式函数名后没有普通句子，就整行裁图，不把 `softmax` 送去翻译。
- 译文只出现在右栏。
- 点击右栏，用左栏高亮对齐：滚到同一页，并标出同一块区域。这不是把译文贴进原文框。
- 测试期划区是本机智谱 GLM-OCR。上线是 OCR API 加现有大模型 API。两套划区只换地址和密钥，右栏裁图不跟着改。翻译用插件里已经配置的大模型 API。

## 2. 右栏怎么排

阅读序：双栏先左后右，再排成一条 Markdown 通读。`.readout` 是文档流，连续滚动。

| 步骤 | 要求 |
| --- | --- |
| 抽 | 有文字层时，正文用文字层原句。主标题、小节、正文、题注按阅读序进入通读 |
| 滤 | 页眉、页脚、纯页码不进主通读 |
| 公式 / 图 / 表 | 右栏使用原页裁图。这些块不进翻译 |
| 译 | 只译标题、小节、正文、题注。沿用现有翻译批次 |
| 挂 | 右栏 `.readout` 连续块。点击该块时，左栏高亮对齐 |

排版尽量做好：阅读序清楚、双栏不串、点击对得上、右栏不叠字、字号可读。任何排版都不得改内容。

## 3. 验收（Attention）

只看网页阅读器左右栏，不看导出的译文文件。公式是否对上，以 `pdf/viewer.html` 里左栏原文和右栏译文为准。当前状态和改法写在 `pdf/high-precision/STATUS.md`。

- [ ] 左栏：pdf.js 原文清晰
- [ ] 右栏：译文连续可滚；公式、图、表是原页裁图，与打开的 PDF 同一套内容
- [ ] 有文字层的正文是文字层原句，不是 OCR 改过的字母
- [ ] 点击右栏，左栏高亮同一区域
- [ ] **无**网页 content / Options 间距回归
- [ ] Issue #40 保持关闭
